# Telegram bot: запись на эпиляцию (MVP)

## Что умеет 
- Клиент: запись на услугу (Hold) + телефон + комментарий
- Админ: confirm/reject кнопками
- Авто-истечение Hold (по умолчанию 12 часов)
- Напоминания 24ч/2ч (по умолчанию включены)
- "Мои записи" + отмена по правилу 12 часов

## Запуск локально
1) Создай Postgres (локально или облако)
2) Скопируй `.env.example` -> `.env` и заполни
3) Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4) Старт:
   ```bash
   python -m app.main
   ```

## Прод (Railway)
- Используй WEBHOOK_URL (например https://<your-app>.up.railway.app)
- PORT обычно задаёт Railway автоматически, но можно оставить 8080
- DATABASE_URL должен быть вида: postgresql+asyncpg://...
- SCHEDULE_VISUALIZATION: 1 = стандартный вид слотов, 2 = расписание дня в стиле недельного вида
- NAME: имя мастера в текстах бота (по умолчанию `Найра`)
- HIDDEN_SERVICE_CATEGORIES: скрыть категории услуг для клиента (через запятую, например `laser` или `sugar,laser`)

### Копия проекта в Railway: чтобы переменные подтянулись сразу
1) В репозитории есть `.env.example` с полным списком переменных для сервиса.
2) При деплое из GitHub в новый Railway-проект открой `Variables` и импортируй этот список (Raw Editor / Paste from .env).
3) Для базы в Railway используй ссылку на переменную плагина Postgres:
   - `DATABASE_URL=${{Postgres.DATABASE_URL}}`
4) Проверь обязательные переменные перед первым запуском:
   - `BOT_TOKEN`
   - `ADMIN_TELEGRAM_IDS` (или `ADMIN_TELEGRAM_ID`)
   - `DATABASE_URL`

> Важно: секретные значения (`BOT_TOKEN`, admin id) Railway не может безопасно «угадать» из кода, их нужно задать один раз в Variables.


## Контент и настройки бренда (без правки кода)
- Все тексты бренда вынесены в файл `content_settings.json` (имя, адрес, контакты, шаблоны напоминаний, рекомендации до/после).
- Для запуска с другим файлом настроек можно задать переменную `PRODUCT_SETTINGS_PATH`, например:
  - `PRODUCT_SETTINGS_PATH=./my_brand_settings.json`
- `NAME` в `.env` по-прежнему поддерживается как override, но если не задан — берётся `brand.name` из `content_settings.json`.
