# Telegram bot: запись на ногтевой сервис (MVP)

## Что умеет
- Клиент: запись на услугу (Hold) + телефон + комментарий, история посещений, перенос/отмена.
- Админ: подтверждение/отклонение заявок, запись клиента вручную, управление перерывами, визуализация расписания.
- Авто-истечение Hold (по умолчанию 12 часов).
- Напоминания за 48ч и 2ч.
- Ежедневные/недельные/месячные отчёты по доходу.

## Аудит кода (структура и поведение)
- **Точка входа**: `app/main.py` запускает Telegram-бота, инициализирует БД, seed-данные и JobQueue (истечение Hold + напоминания + отчёты).【F:app/main.py†L1-L113】
- **Конфигурация**: читается из переменных окружения в `app/config.py` (поддержка нескольких админов через `ADMIN_TELEGRAM_IDS`).【F:app/config.py†L1-L70】
- **База данных**: SQLAlchemy модели в `app/models.py` (users, services, appointments, blocked_intervals, break_rules, settings).【F:app/models.py†L1-L102】
- **Бизнес-логика**: расчёт слотов, ограничения, создание/перенос/отмена записей — в `app/logic.py`.【F:app/logic.py†L1-L210】
- **UI/флоу**: команды, клавиатуры и тексты — `app/handlers.py`, `app/keyboards.py`, `texts.py`.【F:app/handlers.py†L1-L420】【F:app/keyboards.py†L1-L200】【F:texts.py†L1-L66】
- **Сервисные джобы**: авто-истечение Hold в `app/scheduler.py`, напоминания и отчёты в `app/reminders.py`.【F:app/scheduler.py†L1-L61】【F:app/reminders.py†L1-L199】
- **Визуализация расписания**: стили таймлайна и недельного вида в `app/schedule_style.py`; переключается через `SCHEDULE_VISUALIZATION`.【F:app/schedule_style.py†L1-L73】【F:app/handlers.py†L2885-L2953】
- **Легаси-модули**: `booking_flow.py`, корневые `config.py` и `db.py` относятся к старой версии на asyncpg и сейчас не используются точкой входа `app/main.py`. Их стоит удалить или явно пометить как архив, чтобы не путать с текущей реализацией.【F:app/main.py†L1-L113】【F:booking_flow.py†L1-L120】【F:config.py†L1-L63】【F:db.py†L1-L120】

## Конфигурация
Минимальный набор переменных окружения:

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `BOT_TOKEN` | токен Telegram-бота | — |
| `ADMIN_TELEGRAM_IDS` или `ADMIN_TELEGRAM_ID` | список админов (через запятую/`;`) | — |
| `DATABASE_URL` | строка подключения Postgres | — |
| `TIMEZONE` | таймзона для отображения | `Europe/Amsterdam` |
| `WEBHOOK_URL` | URL для webhook-режима | пусто |
| `PORT` | порт сервера | `8080` |
| `SCHEDULE_VISUALIZATION` | 1 = таймлайн дня, 2 = недельный стиль дня | `1` |
| `SLOT_STEP_MIN` | шаг слота (мин) | `30` |
| `BUFFER_MIN` | общий буфер между процедурами (мин) | `10` |
| `MIN_LEAD_TIME_MIN` | минимальное время до записи (мин) | `0` |
| `BOOKING_HORIZON_DAYS` | горизонт записи (дней) | `30` |
| `HOLD_TTL_MIN` | TTL холда (мин) | `720` |
| `CANCEL_LIMIT_HOURS` | запрет отмены/переноса (ч) | `2` |
| `WORK_START` | начало рабочего дня | `09:00` |
| `WORK_END` | конец рабочего дня | `20:45` |
| `WORK_DAYS` | рабочие дни (0=Пн) | `0,1,2,3,4,5` |

> Примечание: `DATABASE_URL` может быть в формате `postgresql://` или `postgres://` — драйвер автоматически приведёт к `postgresql+asyncpg://`.【F:app/db.py†L1-L19】

## Запуск локально
1) Создай Postgres (локально или облако).
2) Создай `.env` и заполни обязательные переменные.
3) Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4) Старт:
   ```bash
   python -m app.main
   ```

## Прод (Railway/Render/etc.)
- Используй `WEBHOOK_URL` (например `https://<your-app>.up.railway.app`).
- `PORT` обычно задаёт платформа автоматически.
- `DATABASE_URL` должен указывать на Postgres; приложение само подставит драйвер `asyncpg`.【F:app/db.py†L1-L19】
- `SCHEDULE_VISUALIZATION`: 1 = стандартный таймлайн, 2 = дневной вид в стиле недельного расписания.【F:app/handlers.py†L2885-L2953】

## Подробная инструкция по использованию

### Для клиента
1) **/start** — бот показывает главное меню.
2) **Записаться**:
   - выбери одну или несколько услуг (кнопки с галочками → «Далее»);
   - выбери дату и время;
   - добавь комментарий (можно «-»);
   - отправь номер телефона кнопкой;
   - подтверди отправку заявки.
   После этого заявка получает статус **Hold**, а администратор видит карточку подтверждения.【F:app/handlers.py†L395-L520】【F:app/handlers.py†L1390-L1585】
3) **Мои записи** — список активных записей. Из карточки можно отменить или запросить перенос (если до визита больше `CANCEL_LIMIT_HOURS`).【F:app/handlers.py†L1680-L1865】
4) **История** — последние завершённые/отменённые визиты.【F:app/handlers.py†L1748-L1774】
5) **Цены и услуги** — перечень активных услуг и цен.【F:app/handlers.py†L430-L520】
6) **Адрес / Контакты** — показывает адрес и контактные данные мастера.【F:texts.py†L8-L22】【F:app/handlers.py†L340-L360】
7) **Подготовка к процедуре** / **Уход после процедуры** — отправляет рекомендации.【F:app/handlers.py†L362-L374】【F:texts.py†L33-L55】
8) **Задать вопрос** — отправляет сообщение мастеру в личные уведомления (админу).【F:app/handlers.py†L376-L395】

### Для администратора
> Админ определяется по `ADMIN_TELEGRAM_IDS/ADMIN_TELEGRAM_ID`.

1) **Админ-меню**:
   - 📅 записи сегодня/завтра/неделя + изображение расписания;
   - 🧾 все заявки (ожидающие подтверждения);
   - 📝 записать клиента вручную;
   - ⏸ добавить перерыв / 🗑 отменить перерыв;
   - быстрый переход в главное меню.【F:app/keyboards.py†L26-L51】【F:app/handlers.py†L256-L360】
2) **Подтверждение заявки (Hold)**:
   - админ получает карточку «Новая заявка» с кнопками ✅/❌/💬;
   - при подтверждении можно указать финальную цену;
   - клиент получает подтверждение и подготовительные рекомендации.【F:app/handlers.py†L1548-L1685】
3) **Работа с записью**:
   - отменить запись;
   - перенести запись (если админ сам её создавал, доступен быстрый перенос);
   - подтвердить визит и финальную цену после посещения.【F:app/handlers.py†L2020-L2189】
4) **Перерывы**:
   - добавить перерыв на конкретный слот или с повторением;
   - отменить ранее созданные перерывы через список выбора.【F:app/handlers.py†L740-L1410】【F:app/handlers.py†L3000-L3055】
5) **Авто-отчёты**:
   - ежедневный/недельный/месячный отчёт по заработку отправляется админам автоматически;
   - время отчётов задаётся в `app/main.py` (21:00 в таймзоне бота).【F:app/main.py†L60-L86】【F:app/reminders.py†L70-L199】
